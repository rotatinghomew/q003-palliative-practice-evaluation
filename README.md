# 安宁疗护实践教学的机会覆盖与轮转安排

这是医学人文教学资料的本地分析工作区。安宁疗护教学实践场域、可接收容量、轮转安排和完成记录均为虚构演练资料，不含真实患者信息。

## 资料

`data/practice-placements.csv` 是 UTF-8 编码的合成演练表，记录学生的目标实践主题、轮转安排和实际完成情况。
`data/practice-context.csv` 记录场域可接收的培养方向、容量、带教资源和有效时间。

字段含义：场域代号、学习者方向、培养周期、教学主题、接收人数、带教资源、申请和排定状态、实际轮转区间及观察到的实践主题。部分记录未开始或未完成，计划状态不代表实践已获得。

表中代号只用于连接同一份演练资料，不对应真实人员、院校或患者。数据没有预先计算的统计结论。

## 运行

需要 Python 3.11 或更高版本，无第三方依赖。运行基线检查：

```sh
python3 -m unittest discover -s tests -v
```

`src/humanities_analytics/inputs.py` 提供通用 CSV 读取入口，将每行作为字符串字段返回。
