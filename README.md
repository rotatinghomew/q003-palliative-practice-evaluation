# 安宁疗护教学实践的多方反馈与课程改进

这是医学人文教学资料的本地分析工作区。安宁疗护教学实践的多角色反馈，均为虚构演练资料，不含真实患者信息。

## 资料

`data/practice-feedback.csv` 是 UTF-8 编码的合成演练表。反馈记录保留实践、地点、回答者角色、表单和记录方式，避免混淆观察来源。
`data/practice-context.csv` 提供与其关联的方案、情境或组织资料，用于理解主表事实的适用范围。

字段含义：实践代号、场域、学习者代号、回答者角色、表单版本、题项、回答、记录者、同意状态。

表中代号只用于连接同一份演练资料，不对应真实人员、院校或患者。数据没有预先计算的统计结论。

## 运行

需要 Python 3.11 或更高版本，无第三方依赖。运行基线检查：

```sh
python3 -m unittest discover -s tests -v
```

`src/humanities_analytics/inputs.py` 提供通用 CSV 读取入口，将每行作为字符串字段返回。
